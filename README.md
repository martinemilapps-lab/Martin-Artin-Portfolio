# Martin Artin Portfolio

An immersive, high-end interactive fashion & creative campaign portfolio built with React and Vite.

## Features

- **Interactive Campaign Gallery**: Dynamic visual sequence displaying haute couture and editorial projects.
- **Micro-animations & Custom Cursor**: Smooth custom canvas interactions and stateful UI cursor transitions.
- **Responsive Layout**: Designed for seamless viewing across mobile, tablet, and desktop viewports.
- **Audio & Sound Feedback**: Optional ambient spatial audio integration.

## Tech Stack

- React 19
- Vite
- HMR & Modern ES Modules
- Vanilla CSS with Glassmorphism & Custom Typography

## Setup & Development

```bash
npm install
npm run dev
```
